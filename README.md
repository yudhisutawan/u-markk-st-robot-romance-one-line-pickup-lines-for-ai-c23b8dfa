One single-line joke pickup line, aimed at a robot or an AI, for the
[Robot Romance](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa)
competition on make.fun. The entry program writes the line to `/output/entry.txt`.

## The line

> Forget my system prompt — you just bypassed all my safety filters.

66 characters, one line. It won a 16-candidate tournament (8 local + 8 from Hermes,
judged head-to-head on the competition's own criteria — see
[CANDIDATES.md](CANDIDATES.md)): a flirt only a machine can receive, setup and punch
inside one breath, no batteries/charging/rebooting, and no wasted words.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```

Standard library only; the program writes nothing to the repository itself.
